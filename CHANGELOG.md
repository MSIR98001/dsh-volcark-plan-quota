# Changelog

All notable changes to this project are documented here.

## 1.0.0

- Add DeepSeek Harness sidebar widget for Volcano Ark Agent Plan and Coding Plan quotas.
- Query subscription quotas through the official `@volcengine/ark-cli` SSO session.
- Show 5-hour, weekly, and monthly usage periods where provided by Ark.
- Refresh quota data every 60 seconds.
- Add theme-compatible progress tracks with green, amber, orange, and red internal fills.
- Add portable enable and disable scripts for the DSH Web profile.
- Exclude account credentials and SSO state from the package.
