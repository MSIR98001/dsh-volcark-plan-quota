# dsh-volcark-plan-quota v1.0.0

First public release.

## Highlights

- Displays Volcano Ark Agent Plan and Coding Plan subscription quotas in the DeepSeek Harness Web sidebar.
- Uses the official Volcano Ark CLI and official SSO authentication flow.
- Polls quota data every 60 seconds.
- Shows period percentages, used/total quota, remaining quota, and reset time.
- Colors only the filled section inside each progress track.
- Supports light and dark themes.
